- jogos de projetil
- motores de física
- fundamentos de js

## ⚙️ Funcionalidades
- mirar com as setas
- atirar com o espaço
- cada flecha no alvo ganha 5 pts
- tem 10 flechas no total

```bash
git clone https://github.com/LucasVeicir/arqueiro-epico
```
